# iSing permission

iSing udzielil ograniczonej zgody na techniczne pobieranie publicznie dostepnych metadanych utworow ze strony lub endpointow iSing.pl w celu stworzenia prywatnego narzedzia Poza Nuty ulatwiajacego wyszukiwanie dostepnych utworow karaoke.

Zgoda dotyczy wylacznie danych publicznych widocznych bez logowania. Projekt nie moze pobierac danych wymagajacych logowania, tresci premium, tekstow piosenek, audio, nagran uzytkownikow, profili uzytkownikow, komentarzy ani prywatnych danych kont.

Gdy iSing udostepni oficjalne publiczne API do tego zastosowania, projekt powinien przejsc z obecnego adaptera technicznego na oficjalna integracje API iSing.
